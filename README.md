# Advanced HTML, CSS & JavaScript Project

## Overview
This project is built using HTML, CSS, and JavaScript.  
It demonstrates responsive design, interactive UI, and API integration.

---

## Features
- Responsive design for all devices (mobile, tablet, desktop)
- Image carousel with next/previous controls
- Joke generator using public API
- Clean and simple UI
- Beginner to intermediate level project

---

## Technologies Used
- HTML5
- CSS3 (Media Queries)
- JavaScript (DOM + Fetch API)
